# v0.3：真实现代行政边界版

**真实边界指注明年代的现代行政区划资料，不是前770年县界复原，也不是2026年现行区划或官方勘界认证。** 此版彻底替换旧六边形，不通过随机拉歪格子制造自然边界。

## 几何与来源

采用 geoBoundaries gbOpen 完整精度源文件，固定上游提交 `9469f09`，保留原始 Polygon / MultiPolygon 的全部坐标、内环与分离部分。选择与旧设计范围相交的完整行政单元，只作纳入判断，不裁切县域、不平滑、不简化、不重新生成分区。

|来源层|代表年代|本图单元数|原始数据来源|来源许可|
|---|---:|---:|---|---|
|CHN ADM3|2017|1997|Lee Beryman / OpenStreetMap contributors|ODbL 1.0|
|PRK ADM2|2019|46|World Food Programme / OCHA ROAP|CC BY 3.0 IGO|

蒙古国ADM2源也完成下载审查，但与本轮筛选条件没有相交单元，未纳入县表。国别代码是现代资料的来源标识，不表示前770年的国界或主权安排。

元数据接口：https://www.geoboundaries.org/api/current/gbOpen/CHN/ADM3/ 、https://www.geoboundaries.org/api/current/gbOpen/PRK/ADM2/ 。逐县源名称、源ID、年代、许可、下载网址和几何SHA256放在 `资料依据.边界依据`。

共2043个行政单元、1,248,246个坐标点。县、区、县级市等统一作为游戏县级空间单元。每个县界与所选来源几何在解析后的JSON层面完全一致；JSON空白及序列化方式不属于几何信息。

## 两张运行时JSON

`data/counties.json` 和 `data/connections.json` 保持原有字段契约。县表总面积按完整源多边形在WGS84椭球上计算，含源文件划入行政区的水面，不应解释为纯陆地面积。七类游戏土地面积以0.01公顷精确闭合。

县际表重建为5733对直接连接，其中239对配置模型水路。陆路从县域主体多边形真实共边取得候选关系；车行类型和绕行距离仍是游戏模型。水路重用原型手工水运走廊，并按新边界重新分段。**真实县界不等于真实古道、真实通航能力或实测路程。** 不为让全图连通而虚构桥梁、渡口或跨境通道；陆路图有6个连通分量。

空通道保持 `null`，不以0替代。水路方向分别读取。网页上的连接线只是拓扑示意，不是古道或河道实际线形。

## 名称、治所和经济数据

县名以边界来源名称为准；取得汉字名称必须满足标准化源名称精确匹配且地名点位于对应县内，不拿最近城镇随意给行政区命名。1921个名称含汉字；其余保留来源原文。洛邑、蓟、曲阜、临淄的已审查历史地点作为搜索别名保留，不据此把现代县界称为古城疆域。

治所字段仍是游戏节点，不保证为真实古治所或现代县政府。人口、土地、地形、国家归属按新旧区域面积相交重分配旧模型，旧范围外采用最近模型区密度外推；资源仍是明确标记的有限剧本配置。这些字段并未升级为实测或历史统计。

## 已知来源质量问题

检测到12对来源间面积重叠，总计13,594,772.196平方米，约13.595平方公里，见 `data/source_topology_issues.json`。保持两个原始多边形并明确报告，没有擅自裁切或移动边界。机器报告状态为 `PASS_WITH_SOURCE_TOPOLOGY_WARNINGS`，不是“全图无重叠”。

旧设计外框与现代海岸、真实县域不完全重合：旧外框未被所选来源覆盖约16,145.895平方公里，完整县域伸出旧外框约324,337.095平方公里。这是不同范围/海岸资料的空间差，不应直接解读为漏画同等面积的真实陆地。完整东周历史范围的考证仍未完成。

CHN下载文件实际2864个单元，而接口元数据标称2867个，此差异已记录。不能把元数据统计当作逐条校验结果。

## 编号迁移

真县与旧六边形不是同一空间单元。新编号采用 `RCHN-…`、`RPRK-…`，由冻结来源层与源单元ID生成，不占用旧EZ编号。`data/id_migration.json`列出全部1195个旧分区与新行政单元的多对多相交面积。它是迁移审查依据，不会自动判断部队、城市、领土或道路应归到哪个新县。

## 重建和网页

冻结源数据位于 `sources/real_boundaries/`；`sources/legacy_grid_counties.json`仅供模型属性重分配和迁移审查，绝不是边界后备来源。

```bash
python -m pip install -r requirements.txt
python scripts/rebuild_real_boundaries.py
python scripts/validate_real_boundaries.py
python -m unittest discover -s tests -v
node --test tests/web-model.test.cjs
python scripts/build_viewer.py --output dist
python -m pip install playwright==1.57.0
python -m playwright install chromium
python tests/web_ui_test.py
```

安装依赖后，日常重建使用冻结输入，不需要查询在线地图。旧的自动六边形生成工作流已退役，旧CLI也改为真实边界构建入口。

在线入口仍是根目录 `index.html`，只读取两张JSON；Pages从main根目录发布。默认图层显示真实县界，县详情明确写出来源年代。离线单文件使用gzip无损压缩相同JSON，保留所有坐标；不是简化地图。数据更新不需要另做一份示意图。

新发布包只包含JSON数据及网页/代码/说明，不含Excel、CSV或单独GeoJSON。历史版本文档只用于审计，不代表当前发布内容。
