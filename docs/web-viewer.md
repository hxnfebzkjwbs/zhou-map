# 东周舆图：v0.3真实现代县界查看器

## 打开

仓库根目录 `index.html` 直接读取 `data/counties.json` 和 `data/connections.json`。GitHub Pages仍从main分支根目录发布，不需要另选docs目录。右上角应显示v0.3，默认图层为真实行政边界。旧页面缓存可用强制刷新清除。

本地源码版运行 `python -m http.server 8000` 后访问 `http://localhost:8000/`。离线单文件 `zhou-atlas-offline.html` 可以直接用现代浏览器打开；两张JSON通过gzip无损压缩内嵌，使用浏览器DecompressionStream解压。没有裁减县界坐标，没有CDN、在线地图服务或第三方字体依赖。

## 展示内容

2043个完整行政单元、5733对直接连接，其中239对另有模型水路。全部边界取自来源多边形，不是规则格子：CHN部分代表2017年，PRK部分代表2019年。**这些是现代行政边界资料，不是前770年县界，也不是2026年现行区划或官方勘界认证。**

每县详情首先显示边界来源与年代，然后显示游戏人口、土地、资源与归属。资料依据页保留原始来源名称、单元ID、完整URL、许可和几何SHA256。地图底部显示OpenStreetMap、geoBoundaries及WFP/OCHA署名。

可以拖动/缩放、地图点选、搜索行政区名称/来源原文/编号或已审查的历史地点别名。洛邑等历史别名指向包含该地点的现代县级单元，不会把现代县界伪称为古城疆域。支持按国家、地形、资源筛选；可切换真实边界、游戏地形、游戏国家、模型人口密度与模型资源图层。

手机端保留抽屉式筛选及详情。网页只读，不改变任何源多边形。完整两表和单县JSON都可下载，无Excel/CSV依赖。

## 寻路

陆路、车行、水路分别按表内公里数计算最短路径；车行排除不能走车的边，水路分别读取两个方向。空通道仍是null，不自动补0，不自动陆水换乘。筛选只影响显示，不删改寻路网络。

新连接按真实县域主体多边形共边关系重建，但通行类型、绕行系数和水运走廊仍是明确的游戏模型，不是古道或古河床考证。屏幕连线只表示连接，不用于按直线估算路程。没有为强制全图连通而虚构桥梁或渡口。

## 已知限制

来源拼接存在12对重叠，约13.595平方公里，保持源几何并单独报告。原图外框只用于挑选完整县域，不再裁切县界，因此新版外缘不同。人口、土地、地形、归属和资源仍包含旧模型的空间重分配，不因边界真实而成为历史统计。

新RCHN/RPRK编号与旧EZ网格编号不兼容；`data/id_migration.json`提供多对多空间对应，不是自动存档转换。详细来源、许可和质量说明见 `NOTICE.md` 与 `docs/v0.3-real-boundaries.md`。
