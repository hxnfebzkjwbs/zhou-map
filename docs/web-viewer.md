# 东周舆图：JSON 网页查看器

## 立即使用

交付的 `zhou_atlas.html`（构建名称为 `zhou-atlas-offline.html`）是完整离线单文件网页，用桌面浏览器打开即可。它内嵌与两张 JSON 表等值的数据，不访问地图平台、CDN 或外部字体，不需要安装前端依赖。

仓库源码入口是根目录 `index.html`，直接读取 `data/counties.json` 和 `data/connections.json`。在仓库根目录运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。源码版需要 HTTP 服务；不应直接用 file 协议打开源码版 index.html。离线单文件版不受此限制。

目前提交了可运行源码和自动测试，不表示已经启用 GitHub Pages 或其他公网托管。

## 数据只使用 JSON

- `data/counties.json`：1195个游戏分区的完整记录。
- `data/connections.json`：3413对直接连接；其中140对同时配置水路。

网页只读，不改写任何县编号、县界、治所、人口、土地、归属、资源或距离。原始 JSON 在网页包中逐字节保留；离线 HTML 内嵌相同数据值。新的网页交付包不含 Excel、CSV 或单独 GeoJSON；仓库旧版文件仅作为原有工程内容保留。

## 界面与操作

桌面为左侧筛选、中间地图、右侧县详情的三栏布局；手机使用可展开的筛选与详情面板。

支持拖动平移、滚轮与双指缩放、地图点选、县名/现代参考名/编号搜索、国家/地形/资源筛选、地形/国家/人口密度/资源四种着色、道路/水路连接显示以及地名标注。

县详情含人口、面积、国家、郡、地形、游戏治所、七类土地面积及比例、资源；连接页以当前县为参考，分别显示出向和入向水路，null显示为“无通道”。资料页保留地名依据、来源链接及模型说明。可查看或下载单县完整 JSON，也可下载完整两表。

键盘 `/` 聚焦搜索；地图获得焦点后方向键平移，`+`、`-` 缩放，`Home` 回到全图。详情分页支持左右方向键；隐藏的手机面板不进入键盘焦点顺序。

## 寻路规则

陆路、车行、水路分别建图，用 Dijkstra 累计表内公里数。车行只使用“能走车”的边；水路严格区分 A→B 与 B→A，不自动进行陆水换乘。筛选只影响显示，不改变最短路计算所用的完整连接网络。

无通道为 null，不能以0代替。起终点为同一县时总程可为0，但这不在县际距离表中创造零距离边。

地图上的连线只是县间连接示意，以游戏治所作显示端点，并非实际古道或河道几何。连线的屏幕长度不用于计算路程。约略比例尺是展示辅助，不替代来源距离。

## 历史与来源边界

本页面展示 v0.2-named 游戏数据，不升级其历史可信度。县界、人口、土地、粗略地形、归属和交通仍含模型设定。现代地名只是回退标签，现代命名参考点与游戏治所分开记录。未分配国家不表示无人居住。地图设计外框及现代低分辨率海岸并非已考证的前770年疆界与海岸。

GeoNames派生地名遵循 CC BY 4.0；来源署名及其他数据说明见 `NOTICE.md`。代码会转义来源内容，并仅允许 http/https 来源链接。

## 构建与测试

生成静态分发目录和离线单文件，不需要第三方 Python 包：

```bash
python scripts/build_viewer.py --output dist
```

逻辑回归：

```bash
node --test tests/web-model.test.cjs
```

浏览器回归：

```bash
python -m pip install playwright==1.57.0
python -m playwright install chromium
python tests/web_ui_test.py
```

本次24项模型测试和37项桌面/手机浏览器检查通过。浏览器检查使用真实离线发布 HTML、真实 Canvas 和原始两表，不是静态截图或模拟数据；通过 set_content 载入以避开制作环境对 localhost/file 导航的限制。测试视口为1512×982与390×844；寻路结果与独立Python实现对照。测试未宣称验证任何公网部署。

GitHub Actions 工作流 `Validate web atlas` 运行相同检查，并保留网页构建产物、截图和报告。数据构建工具和前端查看器相互独立，网页使用无需重新运行历史数据生成器。
