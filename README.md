# zhou-map

公元前 770 年开局的战略游戏地图数据工程。

## 数据契约

运行时仅使用两张基础表：县表、县际距离表。县编号永久稳定，其他数据通过它关联。县是固定的游戏空间单元，不表示公元前 770 年已经普遍实行郡县制。

县表字段：县编号、县名、县界、治所坐标、总面积、地形、初始人口、初始土地用途、自然资源、开局行政归属、资料依据。

县际距离表字段：县 A 编号、县 B 编号、陆路距离、陆路通行类型、水路 A→B 距离、水路 B→A 距离。

- 坐标：WGS84，经度在前、纬度在后；县界使用 GeoJSON Polygon 或 MultiPolygon。
- 面积单位公顷；七类土地用途互斥，合计严格等于总面积。
- 地形仅可为：平原、河谷、丘陵、山地、湿地。
- 自然资源仅可为：铜矿、铅（锡）矿、铁矿、金（银）矿、煤矿、石料、陶土、盐源、玉石。无设定资源使用 `[]`，不记录储量。
- 距离单位公里，存在的通道距离必须大于零。
- 无通道使用 JSON `null` 或 CSV 空单元格；绝不以零代替。没有陆路时，陆路通行类型也必须为空。
- 每对县仅一行，A 编号按字典序小于 B 编号；规范化编号顺序时必须同时交换水路方向。
- 陆路双向共用一个距离；水路两个方向独立。顺逆流速度不同不等于物理距离不同。
- 非直接连接的县通过连接图寻路，不存全县两两距离矩阵。
- 未设置的郡使用 `null`，不得把战国或秦汉的郡提前套入前 770 年。

## 历史依据与模型边界

CHGIS 的主要时序数据覆盖前 221 年至 1911 年，不能直接作为前 770 年县界来源：https://gis.harvard.edu/china-historical-gis

前 770 年洛邑都城背景及遗址位置参考河南省政府公开资料：https://english.henan.gov.cn/2023/01-07/2668848.html

地图目标是整个东周时代的活动区域，而非仅洛阳王畿。外缘、县界、人口、土地用途和道路若由模型生成，必须明确记录为游戏设计，不能宣称为考古复原或历史统计。没有完成考证的数据不得用来源网址掩盖模型假设。

本仓库初始化时只建立了上述契约。各版本的实际数据覆盖、模型假设及验证结果以对应发布说明为准。
