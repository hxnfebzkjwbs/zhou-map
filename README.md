# 东周舆图 · 前770年

当前版本 v0.4.1。网页已经改为读取全历史的 BC770 来源数据，不再使用现代县界、六边形或模拟人口交通。

## 在线打开

https://hxnfebzkjwbs.github.io/zhou-map/

本仓库当前发布的是完整网页程序。**原始大体积地图文件尚未直接上传本仓库**；第一次打开点击“选择历史地图 JSON”，选择你已导出的 `allhistory-770bc-china.json`（不是仅包含名字的 `*-names.json`）。也可以拖放同年份的完整JSON或GeoJSON。数据在浏览器读取，不上传服务器；成功后通过IndexedDB记在本机，下次同一浏览器访问自动打开。无痕模式、存储被禁用或清除网站数据后需重新选择。

对话交付的 `zhou_770bc.html` 已内嵌完整数据，直接用浏览器打开，不需导入或服务器。对话源码包的 `data/territories.json` 是用户上传主文件的原字节副本；将它放入本仓库同一路径后，未缓存的浏览器也可自动加载。

## 功能

名称及来源OID搜索；全部/有名/未命名筛选；地图点选、拖动、滚轮及双指缩放；来源疆域拼接、原始片段、原始线框三种图层；地区详情、原始JSON查看与下载、地区链接，以及手机列表和详情面板。按 `/` 聚焦搜索；地图聚焦后用方向键平移，加减号缩放，Home回中原。

数据中276条来源记录全部保留，其中269条有名、7条未命名，共131806个原始坐标点。三个同名“蓼”保持不同OID，不按名称合并。

## 白地、来源层级和边界

白地是正常的信息空缺，不作为错误，不补新多边形、名称或归属。有几何无名称的记录保留 `name:null`；无来源覆盖的位置也不补面。不能据此认定无人、无主、未开发或水面。

来源名称包含国家、地区、族群和文化，不能把所有276条记录称作县。原文件未提供统一行政层级、上级关系、古代治所、人口、土地、资源、交通通道与距离。网页没有从旧版继承或虚构这些信息，也不把未知通道写成“没有通道”。标签点只用于文字定位，`areaDeg2` 的平方度不是公顷。

拼接图层直接在屏幕上按原始片段分别绘制非零/奇偶填充，分别在同一OID内合并后取共同部分；填充歧义处留白。只为显示，不修改源坐标或补界，不宣称与原网站全部填充规则相同或已独立核定历史疆域。原始图层仍可随时切换。中原/全部范围只改变镜头，不按现代国界裁切数据。

## 项目结构

- `index.html`、`web/`：静态网页，无Python后端或前端安装步骤。
- `data/manifest.json`：数据说明与原始文件校验和；地图本身可由本机导入。
- `tests/`：Node内置测试和浏览器测试；测试样例不是正式历史数据。
- 旧版现代地图及Python工具完整保存在 `archive/v0.3-modern` 分支，不再参与主页运行。

运行逻辑检查：`node --test tests/data.test.cjs`。GitHub Actions还测试本地导入、IndexedDB记忆、刷新、清除缓存、空值和手机布局。对话发布版另用真实276条数据做了29项桌面/手机检查，并核对完整JSON下载逐字节一致。

数据权利和处理说明见 `NOTICE.md`。本次完成来源地图接入和可运行网页；不把来源缺少的县级细分、经济与交通资料冒充为已完成。
